Math Functions API

API для работы с математическими функциями

Доступные эндпоинты:

POST /api/register - Регистрация пользователя
Body: {"username": "test", "email": "test@test.com", "password": "password"}
GET /api/admin/users - Получить всех пользователей (только для ADMIN)
Header: Authorization: Basic base64(username:password)
GET /api/functions - Получить функции (требует аутентификации)
GET /api/operations - Получить операции (требует аутентификации)
GET /api/cache - Получить кэш (требует аутентификации)
